## Plotting codes

This folder contains the code used to generate the plots presented in the paper.

Before running the plotting scripts, update the file paths to point to the performance CSV files generated by the code in `ActiveLearningDFT` and `ActiveLearningExperimental`.

Alternatively, download the results from the Zenodo repository [![DOI](https://doi.org/10.5281/zenodo.23424147). After downloading and extracting the files, update the paths in the plotting scripts to match their locations on your computer.
